# Resonant Cloth Tool: downloads

Installer and updates for **Resonant Cloth Tool**, a Windows tool for organising, checking and building GTA V
freemode clothing packs for FiveM.

## Install

1. Open the [latest release](../../releases) and download **ResonantCloth-win-Setup.exe**.
2. Run it. The installer isn't code-signed, so Windows SmartScreen warns the first time: click **More info**, then
   **Run anyway**.
3. It installs for your Windows account only (no admin rights) and adds Start menu and desktop shortcuts.

## Updates

When a new version is out, the app shows **"Version x is available"** at the top. Click **Update and restart**.
Only the changed files are downloaded. You can also check any time with **Help → Check for updates**.

## First setup

To see clothing on the body, go to **Tools → Settings → Game data folder** and choose a folder holding files you
extracted with OpenIV or CodeWalker from your own GTA V install:

- the folders `mp_m_freemode_01` and `mp_f_freemode_01`
- `mp_m_freemode_01.yft` and `mp_f_freemode_01.yft`, which put hats, glasses and watches on the body

The tool only reads these files. It never copies or edits game files, and it never opens game archives itself.

## Uninstall

Windows **Settings → Apps → Installed apps → Resonant Cloth Tool → Uninstall**. Your settings
(`%APPDATA%\ResonantClothTool`) and your projects are kept.
